# Documentation

Open WebIDE brings your projects and model servers into a self-hosted browser IDE.
Choose a guide based on what you want to do.

| Start here | What you'll find |
| --- | --- |
| [Getting started](start.md) | Install the app, connect a model and open your first project. |
| [Using Open WebIDE](using.md) | Editing, files, agent sessions and reconnecting. |
| [Hosting and administration](hosting.md) | Containers, HTTPS, configuration, upgrades and backups. |
| [Development](development.md) | Build from source, architecture, APIs and contribution references. |
| [Project](project.md) | Release history, planned work and open source credits. |

New to the app? Follow [installation](../README.md#run-with-docker), then
[your first session](first-session.md). Already running it? See
[local and remote projects](workspaces.md) to choose where your files live.
