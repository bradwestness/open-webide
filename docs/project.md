Open WebIDE is MIT licensed and developed in the

- [Roadmap](roadmap.md): remaining work and release readiness.
- [Changelog](../CHANGELOG.md): shipped changes and unreleased development.
- [Open source software](open-source-software.md): dependency and font credits.

Use [GitHub Issues](https://github.com/openwebide/openwebide/issues/new/choose)
to report a bug, request a feature or ask for setup help. Include the app version,
workspace mode and enough steps to reproduce a problem; remove credentials from
logs and screenshots.
