# Getting started

1. [Install and run](../README.md#run-with-docker) using a container, or
   [build from source](../README.md#run-from-source).
2. [Start your first session](first-session.md): register, connect a model server
   and ask the agent about a project.
3. [Choose a workspace](workspaces.md) on the host or on your browser's device.

For access from a phone or another computer, set up
[private HTTPS with Tailscale](tailscale.md). Local folder access requires a
browser that supports the File System Access API and a secure context.

The first public container release is still being prepared. The source-build
instructions work now; [release installation](releases.md) describes the
downloadable files and channels that publication will provide.
